## 루프백 (Loopback)

루프백 주소는 자기 자신의 컴퓨터를 가리키는 특수한 IP 주소이다.

### IPv4 루프백

주소 범위: 127.0.0.0/8
대표 주소: 127.0.0.1
호스트명: localhost

### IPv6 루프백
주소: ::1
호스트명: localhost

## 주요 특징

네트워크 카드가 없어도 사용 가능
로컬 개발 환경에서 서버 테스트용으로 자주 사용
외부로 나가지 않고 자신의 시스템 내에서만 통신

## 사용 예시

```
# 모두 같은 목적지를 가리킴
ping 127.0.0.1
ping ::1
ping localhost
```
