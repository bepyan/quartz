## 개요

**Tiptap**: ProseMirror 기반 라이브러리. 다양한 프레임워크(React, Vue, Svelte 등) 지원.  
https://github.com/ueberdosis/tiptap `star 28.5k`

**Plate**: Slate 기반의 React 전용 에디터 프레임워크. 플러그인 시스템과 커스터마이징 기능 제공.
https://github.com/udecode/plate `star 12.9k`


## 공통점
- 오픈소스 리치 텍스트 에디터 솔루션  
- 강력한 확장성 (플러그인을 통한 기능 추가 가능)  
- 헤드리스(Headless) 형태로 UI 구현에 자유도 높음  

## 주요 차이

| 항목             | Tiptap                                               | Plate                                                   |
|------------------|------------------------------------------------------|---------------------------------------------------------|
| **기반 엔진**    | ProseMirror                                          | Slate                                                   |
| **지원 프레임워크** | React, Vue, Svelte, Vanilla JS 등                    | React 전용                                             |
| **아키텍처**     | 문서 구조와 트랜잭션 관리가 안정적, 헤드리스 UI 제공      | React와 밀접하게 결합된 Slate 기반 확장                  |
| **기본 기능**    | StarterKit 등 WYSIWYG에 필요한 확장이 기본 제공         | 기본 기능은 플러그인으로 추가 필요                       |
| **확장성**       | 공식 확장 패키지로 다양한 기능 손쉽게 추가 가능           | 플러그인 시스템을 통한 세밀한 커스터마이징 가능           |
| **협업 기능**    | 실시간 협업 지원 예시 제공                            | Slate 생태계를 활용한 협업 구현 가능 (별도 개발 필요)      |
| **선택 기준**    | 다중 프레임워크 지원, 빠른 프로토타이핑 및 협업 기능 선호   | React 전용 프로젝트, Slate 구조 및 세밀한 커스터마이징 선호 시 |

## 선택 가이드
- **React 전용 프로젝트**에서 세밀한 커스터마이징 → **Plate**  
- **여러 프레임워크 지원**, 빠른 기본 기능 활용 → **Tiptap**  
- **실시간 협업 기능**이나 **ProseMirror 생태계**를 원한다면 → **Tiptap**  

[[ProseMirror vs Slate]]에 대해서도 참고해보면 좋아 보인다.
